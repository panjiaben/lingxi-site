让 AI 真的看懂
你在跟谁聊、聊到哪了

大多数「AI 代写」是你复制一段话进去，它给你一段漂亮但通用的话。 灵犀换了个做法 —— 它就在你的聊天页里：进聊天自动读最近的来往， 语音会被真听懂，图片会被真看懂，然后给你三条能直接发的候选。

不是猜，是真的在读

下面每一条都来自真机实测（Android 12；微信 8.0.78、陌陌 9.22.9、企业微信 5.0.11、QQ 9.3.55）。

1

真读上下文，不是在猜

进聊天页就自动把最近的来往读出来，而且知道哪条是语音、哪条是图片。读不到就不显示那一行。

上下文里长这样：[语音] 真正说的话 · [图片] 图里是什么
2

真听懂语音

复用宿主自己的 SILK 解码器取到明文 PCM，再走语音识别，识别结果当普通文本消息进上下文和记忆。

实测：企业微信 1.23 秒语音 →「是不是光拾道的时候光到了。」
3

真看懂图片

点开大图那一刻抓到明文位图送视觉模型 —— 报表截图的数字、工地照的细节都能读出来。

实测：一张报表截图 →「K0015 2026.09.23 15:49 5.0 3.0」
4

三条候选是三种策略

稳妥 / 幽默 / 推进各说一件事，最稳那条带 ★ 默认摊开。每条都能行内「换说法」重写，或双击直接改字。

不是三种腔调，是三条不同的走法 —— 挑一条就发。
5

它认得「这个人」

角色人设（这人是我领导 / 客户 / 家人）、长期记忆（跟这个人聊过什么）、学我自己（只学你手打的消息）。

用得越久，它越像你。
6

卡片嵌进聊天页，不挡消息

不是浮在上面的黑框：它插进输入区上方，并让消息列表给它让出真实排版空间，展开 / 收起都会重新量一遍。

压住消息就报警 —— 宁可报错，也不糊你一脸。
支持哪些平台

一个模块，四个宿主，一套共享内核

平台差异全收在一张表里；每个宿主自己的配置 / 记忆 / 日志各自独立、文件名保持原样 ⇒ 升级和融合都不会迁走、不会丢你已经攒下的数据。

边界与风险，如实写

这段不好听，但比「下载即用」诚实 —— 也算是帮你先筛一遍：看完觉得不合适，就别装了。

!

需要 root + LSPosed

它是 LSPosed 模块，不是普通 App。实测 Android 12 跑通；模块要自己手点勾进各 App 的作用域。

!

有封号风险

Hook 聊天软件属于违反其用户协议。请用小号体验，别拿主号当实验田。

!

内容会出设备

聊天内容会发到你自己填的模型接口（你自己的 Key）。灵犀不经过任何第三方中转，配置 / 记忆 / 日志只在本机和宿主目录里。

×

目前不能

解析加密图片 .dat；解析本地加密数据库（微信、企业微信的库都是加密的）；群聊自动发送。

×

微信里必须你手点

注入的合成触摸到不了窗口，所以微信内的所有点击都得你自己按。

!

别让系统杀掉它

要给灵犀开自启动、省电策略改无限制，否则锁屏后收不到消息。后台保活不出任何通知（代价：被清掉后要你下次打开 App 唤醒）。

常见问题

提前答掉，省得来回问

要 root 吗？

要。它是 LSPosed 模块，不是普通 App。没 root 的话装上也用不了。

会用我自己的模型吗？

可以。内置常见平台的填法，用你自己的 API Key，也支持自建 / 中转地址。

会不会乱发？

不会。默认只生成、只填框，发送由你按；想「替你发送」得你自己在「发送模式」里勾。两个都不勾 = 什么都不自动做。

群里会不会刷屏？

不会。群里不出卡片、不生成、不识别媒体。

我的数据在哪？

配置、记忆、日志都在本机（App 私有目录 + 宿主目录）。配置能一键导出备份（下载/Lingxi/），重装可恢复。

换手机 / 重装怎么把设置搬回来？

在「备份 · 恢复」里导一份，重装后点一行「恢复」即可 —— 逐项覆盖，不删你备份里没有的键。

要收费吗？要注册登录吗？

目前不用注册、不用登录、也没有卡密。模型 API 的钱是你自己付给你用的那家。

适合谁 / 不适合谁？

适合：消息量大、要一条条认真回的（销售、客服、装修 / 工程对接、群运营临时拉私聊），想「回得像本人」的玩机党。
不适合：只想装个 App 就用的；担心聊天内容发给第三方模型的；主号不敢冒险的。
